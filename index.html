Features

Everything a landing page needs. Nothing it doesn't.

Zero build step

Plain HTML, CSS, and one small script. Open the file, edit, refresh. Deploy the folder as-is.

Responsive grid

Fluid type with clamp(), a collapsing navigation, and layouts that reflow from phone to desktop.

Fast by default

No fonts to download, no frameworks to parse, no layout shift. Inline SVG icons and a system font stack.

Themeable tokens

Colours, spacing, and radii live in CSS custom properties. Rebrand the whole page from one block.

Accessible markup

Semantic landmarks, a skip link, visible focus rings, and a reduced-motion path for every animation.

Deploy anywhere

Works on any static host: Vercel, Netlify, GitHub Pages, S3, or a folder behind your own nginx.

How it works

Three steps from clone to live.

  1. 1

    Clone the repo

    Fork or download the template, then open index.html in a browser.

  2. 2

    Edit content and tokens

    Replace the copy, point the links at your product, and change the colours in :root.

  3. 3

    Deploy the folder

    Push to your host of choice. There is no build output to generate and no environment to manage.

FAQ

Questions, answered.

Do I need Node.js or a bundler?

No. The template ships as static files. Any static file server works, including python3 -m http.server.

Can I use this for a client project?

Yes. The template is MIT licensed, so you can use, modify, and redistribute it, including commercially.

How do I change the accent colour?

Edit --accent and --accent-2 in the :root block at the top of styles.css.

Does it include a contact form?

Not yet. Point the call-to-action buttons at your form provider or mailto link, or add a form and post it to your own endpoint.
